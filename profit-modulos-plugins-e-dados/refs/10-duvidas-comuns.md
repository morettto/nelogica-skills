# profit-modulos-plugins-e-dados — Dúvidas Comuns

2 artigos da Central de Ajuda da Nelogica (ajuda.nelogica.com.br). Cada verbete traz a URL do artigo original e a data de atualização.

- **Como exportar dados históricos de ativos para o Excel** — Para exportar dados de ativos, acesse o primeiro menu da plataforma e clique na opção Exportar Dados Históricos: Escolha o diretório de exportação e exporte os ativos previamente adicionados: *(fonte: https://ajuda.nelogica.com.br/hc/pt-br/articles/360044287672-Como-exportar-dados-hist%C3%B3ricos-de-ativos-para-o-Excel, atualizado 2026-09-28)*
- **Por que não consigo exportar mais de 20.000 linhas para o Excel?** — Ao utilizar a opção Copiar Estudos para Excel, é possível copiar para o Excel os dados do ativo juntamente com as informações dos indicadores utilizados. A funcionalidade possui um limite de 20.000 linhas para a cópia dos dados. Esse limite é aplicado à própria funcionalidade, portanto, ao utilizar essa opção, não é possível copiar mais de 20.000 linhas, independentemente da versão da plataforma utilizada, como Profit Pro ou Profit Ultra, entre outras. Caso seja necessário trabalhar com uma quantidade maior de dados, é possível utilizar outras opções de exportação disponíveis na plataforma, conforme o tipo de informação que deseja obter. Veja *(fonte: https://ajuda.nelogica.com.br/hc/pt-br/articles/56471751476891-Por-que-n%C3%A3o-consigo-exportar-mais-de-20-000-linhas-para-o-Excel, atualizado 2026-11-03)*
